# 🚀 Setup Guide — Joy's Profile README

Follow these 3 steps and your profile will look 🔥.

## 1. Add the README

Your profile README lives in a **special repo named exactly like your username**:
`JoyTarafder/JoyTarafder`.

- Put `README.md` in the **root** of that repo.
- Commit & push to the `main` branch.

## 2. Enable the Snake Animation 🐍

The snake is generated by a GitHub Action.

1. In the `JoyTarafder/JoyTarafder` repo, create this folder path: `.github/workflows/`
2. Put `snake.yml` inside it → final path: `.github/workflows/snake.yml`
3. Commit & push.
4. Go to the repo's **Actions** tab → open **🐍 Generate Snake Animation** → click **Run workflow**.
5. Wait ~1 minute. It creates an `output` branch with the snake SVGs.

After the first run, the 🐍 section in your README comes alive. It then auto-refreshes every 12 hours.

> If Actions is disabled, enable it: repo **Settings → Actions → General → Allow all actions**.

## 3. Replace the Placeholders ✏️

Open `README.md` and search-and-replace these (they're also listed in a comment at the top of the file):

| Placeholder | Replace with |
|---|---|
| `YOUR_LINKEDIN` | your LinkedIn profile URL |
| `YOUR_PORTFOLIO` | your portfolio/website URL |
| `YOUR_EMAIL` | your email address |
| `YOUR_TWITTER` | your Twitter/X profile URL |
| `YOUR_FACEBOOK` | your Facebook profile URL |

Also tweak the **Tech Stack** section — remove anything you don't use, add anything missing. The visual icon row uses [skillicons.dev](https://skillicons.dev); just edit the `i=` list.

---

## 🎨 Want a different color theme?

All the stat cards use the `tokyonight` theme. To change the whole vibe, swap `theme=tokyonight` in the stats/streak/trophy URLs for one of: `radical`, `dracula`, `gruvbox`, `merko`, `onedark`, `cobalt`, `synthwave`, `highcontrast`.

Enjoy! ✨
